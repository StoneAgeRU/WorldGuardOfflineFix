# WorldGuardOfflineFix

**Плагин-фикс для WorldGuard**, который позволяет владельцам регионов удалять игроков, даже если они находятся офлайн.

## 🐛 В чем проблема?
В стандартном WorldGuard (версии 7.x) при попытке удалить игрока командой `/rg removemember`, плагин пытается получить его UUID у серверов Mojang. 
Если игрок находится в сети — всё работает. Но если игрок **офлайн**, Mojang не может выдать его UUID, из-за чего команда завершается ошибкой (или просто молчит), и игрок **остается в регионе навсегда**.

## 🛠 Как это фиксит наш плагин?
Этот плагин напрямую обращается к базе данных регионов WorldGuard. Он берет никнейм игрока и удаляет его из списка участников, **игнорируя проверку UUID** и статус онлайна. 

## 💻 Команды и права
*   `/rgremove <регион> <ник>` — удалить игрока из региона.
*   **Права:** 
    *   `wgofflinefix.admin` — позволяет удалять игроков из **любых** регионов (по умолчанию только у операторов).
    *   Если у игрока нет этого права, он сможет использовать команду **только для тех регионов, где он является владельцем**.

## 📦 Установка
1. Скачайте `WorldGuardOfflineFix-1.0.jar` из раздела **Releases** справа.
2. Закиньте файл в папку `plugins` вашего сервера.
3. Перезапустите сервер.

*Требования: Paper/Purpur 1.21+ (Java 21), WorldGuard 7.0.15 (тестировалось на WorldGuard 7.0.15 и WorldEdit 7.4.2)*
