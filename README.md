# WorldGuardOfflineFix

Плагин-фикс для WorldGuard, который позволяет владельцам регионов удалять игроков, даже если они находятся офлайн.

## Проблема
Стандартная команда WorldGuard `/rg removemember` не работает, если игрок офлайн. Плагин пытается получить UUID игрока у Mojang, терпит неудачу и ничего не удаляет.

## Решение
Этот плагин напрямую обращается к базе данных регионов WorldGuard и удаляет никнейм, не запрашивая его онлайн-статус.

## Команды и права
*   `/rgremove <регион> <ник>` — удалить игрока из региона.
*   Право `wgofflinefix.admin` — позволяет удалять игроков из **любых** регионов (по умолчанию только у операторов). Обычные игроки могут удалять только из своих регионов.
